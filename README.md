# Memory World - Tactical RPG Roguelike

**Полнофункциональная игра о памяти, тактике и выживании в процедурном мире!**

## 🎮 Что это?

Memory World — это уникальная тактическая RPG с рогалайк элементами, где главная механика — **ПАМЯТЬ**. Каждое существо имеет ограниченный запас памяти, который используется для всех действий в бою.

## ⚡ Основные возможности

### 🧠 Система Памяти
- **Универсальный ресурс** — память определяет интеллект, силу и тактику
- **Редкость монстров** влияет на объем памяти (8-40)
- **Регенерация памяти** каждый раунд боя
- **5 типов ИИ** — Агрессивный, Тактик, Хищник, Защитник, Маг

### 🗺️ Процедурный мир (20×20)
- 8 типов биомов с уникальными характеристиками
- Случайно размещенные враги, города, подземелья
- Система исследования и открытия локаций
- День/ночь и система погоды

### ⚔️ Тактические бои (10×10)
- Пошаговая система с инициативой
- 9 типов действий (атака, защита, блок, спецудар, ультимейт и т.д.)
- Враги с разными стратегиями боя
- Система урона, защиты и регенерации

### 🔧 Геометрический крафт
- 6 типов геометрических фигур (сфера, круг, квадрат, куб, прямоугольник, треугольник)
- 200 процедурных рецептов
- Каждый предмет имеет уникальное имя (Огненный Меч Хаоса)
- Статы зависят от комбинации фигур

### 💰 Система лута
- Процедурная генерация предметов с редкостью
- 5 уровней редкости (обычный, редкий, эпик, легендарный, мистический)
- Случайные префиксы и суффиксы для названий
- Эффекты и баффы на предметах

### 🎯 Боевые действия
| Действие | Цена памяти | Описание |
|----------|-------------|---------|
| Атака | 1 | Базовая атака на врага |
| Защита | 1 | Боевая стойка, снижение урона |
| Блок | 1 | Активное блокирование |
| Спецудар | 3 | Усиленная атака (1.5x урон) |
| Заклинание | 2-4 | Магическая атака |
| Исцеление | 2 | Восстановление HP |
| Уворот | 2 | Активный уход от урона |
| Ульта | 5 | Мощная финальная атака |

## 🚀 Управление

### На карте мира:
- **Клик мыши** — перемещение
- **SPACE** — пауза
- **S** — сохранить игру
- **L** — загрузить игру
- **ESC** — выход из боя

### В бою:
- **Клик на врага** — выбрать цель
- **Кнопки действий** — использовать способности
- **Память** — ресурс для действий

- **Темный фэнтези** (Dark Fantasy)

- **Процедурный хоррор** атмосфера
- **Цветовая система редкости:**
  - Обычный: серый
  - Редкий: синий
  - Эпик: фиолетовый
  - Легендарный: золотой
  - Мистический: красный

- `src/world-generator.js` — генерация мира

## 🎮 Как играть

1. **Откройте `index.html`** в браузере
2. **Исследуйте мир** — кликайте на новые локации
3. **Встречайте врагов** — случайные столкновения с монстрами
4. **Сражайтесь тактически** — используйте память для действий
5. **Собирайте лут** — получайте предметы и фигуры для крафта
6. **Крафтьте** — комбинируйте фигуры для создания нового оружия
7. **Прокачивайтесь** — повышайте уровень и способности

## 💾 Сохранение игры

Игра автоматически сохраняется в `localStorage`:
- Нажмите **S** для явного сохранения
- Нажмите **L** для загрузки сохранения
